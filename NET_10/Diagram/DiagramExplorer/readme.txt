DiagramExplorer
------------------------------------------------------------------------------
Shows the main features of FlexDiagram.

The sample includes the following demos:

 - Introduction
 
 Unbound
   - FlexChart Family
   - Dynamic Graph
   - Diagram Clock
   - Custom Shape
 
 Data Binding
   - OrgChart
   - Animals
   - Node Template
   - Nested Diagrams
 
 Interaction
   - HitTesting
   - Selection
   - Tooltips
   - Collapsible
 
 Usage Scenarios
   - Literature
   - Decision Tree
   - Programming Languages
   - Family Tree
